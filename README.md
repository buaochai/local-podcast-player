# 本地播客

听手机里本地音频播客的网页，可以「添加到主屏幕」当 App 用（PWA）。

## 功能
- 从手机里选择音频文件（mp3、m4a、aac、wav、ogg、opus、flac），可以一次选多个，按文件名排序
- 播放 / 暂停、后退 / 快进 15 秒、上一个 / 下一个，拖动进度条
- 倍速：0.8x – 2x，会记住上次的选择
- 每个文件自动记住听到的位置（按「文件名 + 文件大小」识别），重新选回同一个文件会接着播放
- 播放记录列表：显示进度和最后收听时间
- 导出 / 导入记录（JSON 文件），用来备份或换浏览器
- 锁屏和耳机按钮可以控制播放
- 断网也能打开网页

## 注意
- 网页不能直接读手机文件夹，每次打开后要重新选择音频文件。
- 播放记录存在浏览器的 localStorage 里，清除浏览器数据会被删除，请时常「导出记录」。

## 文件
- `index.html`：整个网页
- `manifest.webmanifest`、`sw.js`、`icon*`：PWA（主屏幕图标、离线缓存）

改了网页文件时，要同时升 `index.html` 里的 `app-version` 和 `sw.js` 里的 `CACHE` 版本号，并写 `CHANGELOG.md`。
