              本地播客 v
              
          
              点右边按钮检查并更新到最新版本
              
        
              
        
      
              

      
              功能
              
      
                
        
              • 点右上角「＋」选音频文件（mp3、m4a 等），可以一次选多个；音频会保存在网页里，下次打开直接播放
                • 
        
              • 首页右上角的 RSS 图标可以订阅播客：填 RSS 地址，节目列表自动抓取，在线播放；单集「!」里可以下载到本机离线听
                • 
        
              • 按音频文件里的「专辑」信息自动分成不同的播客节目，并显示节目封面
                • 
        
              • 点节目封面进入节目，看到每一集的进度；点每一集右边的「!」查看文件信息和更多操作
                • 
        
              • 长按某一集（或点右上角「选择」）可以多选，选好后一起移动到专辑或删除
                • 
        
              • 底部悬浮播放器：上一集 / 下一集、后退 / 快进 15 秒、拖动进度条
                • 
        
              • 点「1x」选播放速度，点月亮设置定时关闭（按时间或播完本集）
                • 
        
              • 每一集的「!」→「AI 转文字」可以识别成文字（需要自己的 API Key），点一句话就跳到那里播放；多选后点「转文字」、或长按专辑 →「AI 转文字」可以整批识别
                • 
        
              • 点书签按钮收藏当前时间点，可以写上收藏原因；之后点一下就能跳回那里。首页右上角的书签图标是收藏入口：专辑 → 集 → 收藏的时间点和备注
                • 
        
              • 首页右上角的文件夹按钮可以新建专辑；选中集后点「移动到专辑」；长按专辑封面可以重命名或删除
                • 
        
              • 专辑页的「编辑」可以改专辑名称和创作者，创作者显示在锁屏和通知栏的播放信息里
                • 
        
              • 每一集自动记住听到的位置
                • 
        
              • 锁屏和通知栏显示节目封面，可以用锁屏和耳机按钮控制播放
                • 
      
              

      
              AI 文稿
              
      
              用你自己的 API Key，把音频识别成带时间的文字，再由文本模型自动分章节。语音识别支持阿里云百炼 Fun-ASR、OpenAI、Groq、硅基流动、Gemini、OpenRouter 和自定义接口；分章节支持 Claude、DeepSeek、通义千问、智谱、Kimi、豆包、混元、OpenAI、Gemini 等。
